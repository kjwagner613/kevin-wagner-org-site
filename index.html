Sovereign Builder · Impala Streamer

Impala Streamer - Home Version is a media server designed for ease of use, absorbing all common friction present in contemporary alternatives. It is a free download, that can be live, serving your media to all home network attached devices 5 minutes after download. Built to reduce algorithmic noise, advertising pressure, and platform-driven behavioral shaping. It is a user-controlled way to enjoy your media library without hardware maintenance and upgrades involved in typical home server scenarios. Having no external dependencies, it is sovereign and, being native HTML5, FAST.

Impala Streamer - Cloud Version, beginning with the Home Version as its core, adds a cloud based authentication that enables secure remote access and synchronization across multiple devices, while maintaining the same user-centric, ad-free experience as the Home Version. Cloud offers additional features such as SyncPlay and Coast to Coast, meant to be tools to bridge physical distance between users. A group can watch a movie, each at different locaions, with control from one master device, or shared across the group. The video remains synchronized for all participants. Coast to Coast provides a similar experience, meant for two people, with the added functionality of hands free or push to talk communication.
